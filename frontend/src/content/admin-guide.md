This guide is for System Admins.

## Creating users

1. Open **User administration** and choose **New user**.
2. Enter the full name, a unique email address, one role (Employee, Manager, Payroll Admin or System Admin) and a time zone.
3. Missing or invalid fields are named and nothing is created. An email already in use, even by a deactivated account, is rejected.
4. The new user receives an email with a single-use link to set their password, then can sign in.

## Assigning managers

1. Select a user in the list and choose a manager.
2. Only active users with the Manager role can be assigned. A user cannot be their own manager.
3. A manager who has reports cannot be changed to another role.
4. You can also edit name, role and time zone, and deactivate a user who has left. Deactivating ends their sessions and keeps their time entries. You cannot deactivate your own account.

## Setting up clients

1. Open **Clients, projects and tasks** and choose **New client**. Client names must be unique.
2. Archiving a client stops its projects accepting new time entries. Existing entries stay visible.

## Projects and bill rates

1. Select a client and create a project with a name and an hourly bill rate of 0 or more.
2. Negative or non-numeric rates are rejected.
3. Changing a rate affects reporting only. Recorded time is unchanged.
4. Choose whether the project is billable by default.
5. Bill rates are held for reporting. There is no invoicing or payment.

## Tasks

1. Select a project and add a task by name. It can be chosen straight away.
2. Archive a task to stop it being offered for new entries. Older entries keep showing it.
